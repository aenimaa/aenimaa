### Hi, I'm Nima 👋

I'm a product designer in Tehran. I mostly work on fintech and B2B SaaS: lending flows, admin panels, and the design systems that hold them together.

My favourite problems are the messy ones, where a few people share the same process, and nobody can quite say where it breaks. I like to understand what's actually going on before I draw anything. I also write my decisions down, so whoever comes next knows why things look the way they do.

Lately I've been building as well as designing. This is where those experiments live.

#### 🛠️ Things I've made

- **[Focus Mode for YouTube](https://github.com/aenimaa/focus-mode-for-youtube)** is a small Chrome extension that tucks away recommendations, comments and Shorts, so you only watch the video you came for. No tracking, no network requests. [Website](https://aenimaa.github.io/focus-mode-for-youtube/)
